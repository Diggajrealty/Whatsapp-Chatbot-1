## 🚨 Troubleshooting

### Dashboard doesn't look new?
```bash
# Hard refresh browser
Ctrl + Shift + R (Windows/Linux)
Cmd + Shift + R (Mac)

# Or clear cache
F12 → Application → Clear Storage → Clear
```

### Tabs not working?
```bash
# Check console (F12)
# Should see: [DASHBOARD] Browser connected
# Should NOT see: Element not found errors
```

### Analytics not updating?
```bash
# Click "↻ Refresh" button
# Send test messages
# Check: whatsapp_session/analytics.json
```
